# 시나리오 데이터 형식

시나리오는 `data/scenarios/<id>/` 폴더 하나로 정의합니다. 폴더 이름과 `id`가 같아야 합니다.
새 게임 화면에서 시나리오를 고르면 그 시나리오의 데이터와 파라미터가 적용됩니다.
해석기: `scripts/Systems/scenario_manager.gd`, 파라미터: `scripts/Systems/scenario_rules.gd`

```
data/scenarios/heukpung_winter/
├── scenario.json      # 시나리오 정의 (필수)
├── events/            # 이 시나리오에서만 일어나는 기연 (선택)
├── endings/           # 이 시나리오 전용 엔딩 (선택, docs/엔딩_데이터_형식.md)
├── npcs/              # 이 시나리오에만 나오는 인물 (선택)
└── sects/             # 이 시나리오에만 나오는 문파 (선택)
```

전용 폴더의 데이터는 공용 데이터(`data/events/`, `data/endings/`, `data/npcs/`, `data/sects/`)에 **더해서** 읽습니다.
id가 공용 데이터와 겹치면 공용 데이터가 우선하고 전용 데이터는 경고와 함께 무시됩니다.

## scenario.json

```json
{
  "id": "heukpung_winter",
  "title": "흑풍의 겨울",
  "order": 2,
  "era_name": "흑풍",
  "description": "세를 불린 흑풍채가 청운검파를 노립니다. ...",
  "start_roles": ["young_disciple", "leader"],
  "sects": ["heukpung", "namgung"],
  "sect_overrides": { "heukpung": { "disciple_count": 22, "attitude": -80 } },
  "parameters": { "time_limit_years": 5, "legacy_enabled": false, "exp_scale": 1.5, "end_on_victory": true },
  "victory_endings": ["winter_defended"]
}
```

| 필드 | 설명 |
|---|---|
| `id`, `title`, `description` | 필수. 설명은 새 게임 화면에 표시 (`\n` 줄바꿈) |
| `order` | 목록 순서 (작을수록 위) |
| `era_name` | 연호. "흑풍 3년 가을"처럼 날짜 앞에 붙음. 생략하면 "천하대란" |
| `start_roles` | 고를 수 있는 시작 역할 (`young_disciple`, `wanderer`, `mercenary`, `leader`). 생략하면 전부 |
| `player_sect` | 플레이어 문파 id. 생략하면 `is_player_sect`인 문파 |
| `sects` | 등장하는 강호 세력 id 목록. 생략하면 플레이어 문파를 뺀 전부 |
| `sect_overrides` | `{ 문파 id: { 수치 필드: 값 } }`. 플레이어 문파도 덮어쓸 수 있음 |
| `parameters` | 게임 길이·난이도 파라미터 (아래 표) |
| `victory_endings` | 이 시나리오에서 승리로 치는 엔딩 id (공용 엔딩 또는 `endings/` 폴더의 전용 엔딩). 평가 점수에 승리 보너스가 붙음 |

전용 엔딩은 `endings/` 폴더에 엔딩 JSON으로 둡니다. 보통 `"auto": false`로 두고 기연의 `end_game` 효과로 도달시킵니다.

## 파라미터

모두 기본값이 있습니다. 새 게임 화면의 **세부 설정**에서 일부를 바꿀 수 있고,
그 값은 시나리오 값보다 우선하며 세이브에 함께 저장됩니다.

| 파라미터 | 기본값 | 범위 | 의미 |
|---|---|---|---|
| `time_limit_years` | 0 | 0~200 | 제한 연수. 마지막 해 겨울이 끝나면 **시대 종결**. 0이면 제한 없음 |
| `legacy_enabled` | true | – | 세대 전승 허용 |
| `max_generations` | 0 | 0~20 | 최대 세대. 0이면 제한 없음 |
| `income_scale` | 1.0 | 0.1~5 | 계절 수입 배율 |
| `upkeep_scale` | 1.0 | 0~5 | 유지비 배율 |
| `exp_scale` | 1.0 | 0.1~5 | 경험치 배율 (성장 속도) |
| `event_rate` | 1.0 | 0~1 | 계절마다 기연이 일어날 확률 |
| `world_growth_scale` | 1.0 | 0~5 | 강호 세력의 연간 성장 배율 |
| `enemy_strength_scale` | 1.0 | 0.3~3 | 전투 적 체력·피해, 문파전 적 전력 배율 |
| `ai_aggression` | 1.0 | 0~3 | 세력 AI의 호전성. 세력끼리의 공격과 플레이어 침공 가중치에 곱한다 (침공은 `event_rate`도 곱한다) |
| `end_on_victory` | false | – | 승리 엔딩에 도달하면 시나리오를 끝냄 (단기 시나리오용) |

## 끝나는 방식

| 상황 | 결과 |
|---|---|
| 제한 연수의 마지막 겨울이 끝남 | 시대 종결 (`era_end`) — 평가 화면 |
| `end_on_victory`이고 승리 엔딩 도달 | 시나리오 완수 (`scenario_complete`) |
| 생을 마치는(`final`) 엔딩, 전승 불가 | 이야기의 끝 (`story_end`) |
| 게임오버 조건 (문파 해산 등) | 게임오버 |
| 그 밖의 엔딩 도달 | 엔딩 기록 후 계속 진행 (세대 전승 가능) |

엔딩 화면에는 점수와 등급이 나옵니다. 점수 항목과 등급 기준은 `GameBalance`의 `SCORE_*` 값입니다.

## 시나리오 전용 기연 쓰기

- 기연 조건 `scenario`(`in: [시나리오 id]`)로 공용 기연을 특정 시나리오에서만 일어나게 할 수 있습니다.
- `years_left`(남은 연수)로 "마지막 해에만" 같은 조건을 만들 수 있습니다.
- 전용 엔딩은 기연 효과 `{ "type": "end_game", "ending": "<엔딩 id>" }`로 도달합니다.
