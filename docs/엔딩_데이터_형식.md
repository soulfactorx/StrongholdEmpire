# 엔딩 데이터 형식

엔딩은 `data/endings/` 폴더의 JSON 파일 하나당 하나씩 정의합니다.
시나리오 전용 엔딩은 `data/scenarios/<id>/endings/`에 둡니다.
해석기는 `scripts/Systems/ending_manager.gd`, 조건 문법은 기연과 같습니다 (`docs/기연_데이터_형식.md`).

## 예시

```json
{
  "id": "unify_righteous",
  "title": "정파 통일",
  "description": "문주로서 청운검파를 이끌고 강호에 새 질서를 세웠습니다. ...",
  "priority": 70,
  "tone": "victory",
  "final": false,
  "conditions": [
    { "type": "role", "in": ["LEADER"] },
    { "type": "sect", "field": "reputation", "op": ">=", "value": 100 },
    { "type": "character", "field": "morality", "op": ">=", "value": 65 },
    { "type": "subjugated_count", "op": ">=", "value": 2 }
  ]
}
```

## 필드

| 필드 | 설명 |
|---|---|
| `id`, `title`, `description` | 필수. 게임오버 id(`era_end` 등)와 겹치면 안 됩니다 |
| `auto` | 기본 `true`: 계절마다 조건을 판정해 자동으로 도달합니다. `false`면 기연의 `end_game` 효과로만 도달합니다 |
| `priority` | 자동 엔딩에 필수. 여러 엔딩의 조건을 동시에 만족하면 **높은 쪽**이 선택됩니다. 자동 엔딩끼리 겹치면 안 됩니다 |
| `tone` | `victory`(금색) · `tragedy`(붉은색) · `neutral` — 엔딩 화면 제목 색 |
| `final` | `true`면 이 엔딩으로 주인공의 생이 끝납니다 (아래 참고) |
| `conditions` | 기연 조건 목록. 자동 엔딩은 하나 이상 필요 |

### 엔딩에 자주 쓰는 조건

- `subjugated_count`: 굴복시킨 강호 세력 수
- `generation`: 현재 세대
- `world_sect`의 `field: "subjugated"`(0 또는 1): 특정 세력을 굴복시켰는지
- `role_history`: 거쳐 온 역할 (예: 막내 제자 출신 문주)
- `relationship_type`, `bond`: 인연의 종류와 깊이

## 엔딩에 도달한 뒤

| 엔딩 종류 | 결과 |
|---|---|
| 일반 엔딩 | 엔딩을 기록하고 계속 진행. 조건(55세 또는 레벨 10)을 채우면 세대 전승 |
| `final` 엔딩, 전승 가능 | 생 종료. 계절이 멈추고, 나이와 관계없이 곧바로 후계자로 전승 |
| `final` 엔딩, 전승 불가 (시나리오 규칙) | 이야기의 끝 (`story_end`) |
| 시나리오 승리 엔딩 + `end_on_victory` | 시나리오 완수 (`scenario_complete`) |

엔딩 화면에는 이번 판의 요약(역할 변천, 굴복시킨 세력, 무공, 주요 인연)과 점수·등급이 표시됩니다.

## 검증

- 스모크 테스트가 모든 엔딩 파일을 검증하고, 자동 엔딩 우선순위가 겹치지 않는지 확인합니다.
- **새 자동 엔딩을 추가하면** `smoke_test.gd`의 `_test_every_ending_reachable`에
  그 엔딩에만 도달하는 상태를 함께 추가해야 합니다. 빠뜨리면 테스트가 실패합니다.
