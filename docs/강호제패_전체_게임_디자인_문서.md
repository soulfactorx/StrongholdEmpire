# 강호제패 (强胡制覇) Remake
## 무협 전략 시뮬레이션 RPG 전체 게임 디자인 문서

**버전**: 1.0 (2026년 6월 기준 종합 정리)  
**모티브**: Romance of the Three Kingdoms 8 Remake + Destiny and Strategy Expansion Pack  
**장르**: 무협 전략 시뮬레이션 + RPG + 샌드박스  
**핵심 슬로건**: "모든 강호인이 주인공이 되는, 직접 창안하는 무협 대서사"

---

## 1. 게임 개요 및 핵심 철학

### 1.1 게임 컨셉
플레이어는 작은 문파의 문주(또는 창파자)가 되어 제자를 키우고, **자신만의 무공을 창안**하며, 기연을 잡아 정파·사파·마교가 얽힌 강호를 제패하는 **무협 전략 시뮬레이션 RPG**입니다.

코에이 삼국지 시리즈(특히 ROTK 8 Remake)의 **장수 중심 전략 + 관계 진화** 철학을 무협 세계관에 완전히 이식했습니다.

### 1.2 핵심 철학 (ROTK 8 Remake에서 차용)
- **모든 캐릭터가 주인공**: 문주뿐만 아니라 막내 제자, 낭인, 간자, 자객 등 어떤 신분으로 시작해도 полноцен한 주인공 스토리가 펼쳐집니다.
- **깊은 관계 본드 시스템**: 사제지간, 연애, 혈맹, 원한 등이 시간에 따라 진화하고 전투·기연·결말에 큰 영향을 줍니다.
- **개인 서사 + 대전략 결합**: 개인의 복수·사랑·성장이 문파 전략·전쟁과 자연스럽게 연결됩니다.
- **창안의 재미**: 무공을 직접 만들고 명명하며, 문파 고유 비전으로 발전시킵니다.
- **PK 스타일 확장성**: 기본 게임 + 대형 확장 콘텐츠(추가 시나리오, 신규 무공, 관계 이벤트)로 장기 생명력 확보.

### 1.3 USP (Unique Selling Points)
1. 무공 창안 + 신분 전환 + 관계 드라마의 완벽한 결합
2. ROTK 스타일 전략 시뮬레이션 + 무협 기연 로망
3. "한 번 플레이 = 하나의 무협 소설, 여러 번 플레이 = 수십 편의 다른 소설"

## 2. 세계관 및 시대 배경

### 2.1 시대 설정: 천하대란기
- 중앙 제국(가상 천제국 또는 후기 대명풍)이 급격히 쇠퇴.
- 황실 권력 공백 → 강호 문파들이 실질적 세력으로 부상.
- 정파 연합 vs 사파 연합 vs 마교 + 황실 잔당 + 외적 침공이 동시에 발생.
- **삼국지 말기와 유사한 혼란의 시대** — 누구든 천하를 노릴 수 있음.

### 2.2 스토리 테마 (영화·소설 영감)
- **진용(金庸)**: 가문 원한, 무공 전승, 국가 대의 vs 개인, 삼각 로맨스, 배신과 화해.
- **고룡(古龍)**: 냉혹한 자객, 운명적 만남, 비극적 무협.
- **영화**: 《영웅》(정치적 희생), 《와호장룡》(금단의 사랑과 배신), 《비검》(간자와 삼각관계).
- 주요 아크: 복수와 용서, 승계와 배신, 금단의 사랑, 간자 이중생활, 마교 대침공, 천하 통일 vs 새로운 질서.

## 3. 플레이 시스템 — 동적 신분 전환 시스템

### 3.1 플레이 가능한 주요 신분
| 신분           | 주요 스타일               | 강점                          | 위험/약점                  | 무공 특화 방향          |
|----------------|---------------------------|-------------------------------|----------------------------|-------------------------|
| **문주**      | 전략 시뮬레이션 (ROTK 군주) | 전체 경영, 전쟁 지휘           | 내부 배신 위험 높음        | 대군 지휘·버프형       |
| **총관** | 부서 경영 + 내부 정치     | 특정 분야 전문, 음모 개입      | 문주와 갈등 가능           | 분야 특화 무공         |
| **막내 제자** | 개인 성장 RPG             | 기연 탐험, 스승과의 유대       | 자원·권한 부족             | 성장형 자유 조합       |
| **낭인**      | 자유 탐험 + 의뢰          | 최고 자유도, 문파 이적 쉬움    | 지원 부족, 고립            | 개인 최적화            |
| **간자**    | 침투·정보·사보타주        | 적 내부 정보, 이중 플레이      | 정체 노출 시 즉사급 위험   | 은밀·기습·정보형       |
| **자객**    | 표적 제거 + 스텔스        | 단독 행동, 높은 보상           | 도덕성 하락, 현상금        | 은밀·독·제거형         |
| **청부객/용병** | 중립 계약 수행           | 다양한 파벌과 관계 맺기        | 충성심 의심받음            | 실용·다양형            |

### 3.2 신분 전환 메커니즘
- **시작 신분 선택** + 진행 중 자연스러운 전환.
- 기연·선택·성과에 따라 승진/강등/이적/배신 발생.
- **멀티 퍼스펙티브**: 중요 이벤트에서 자신 + 제자 + 동료를 순차 제어.
- **후대 시스템**: 한 인생 종료 후 자식·제자·후계자로 이어 플레이.

## 4. 무공 창안 시스템 상세 스펙

### 4.1 기본 구조
- **카테고리**: 검법, 장법, 권법, 퇴법, 지법, 암기, 경공, 내공심법.
- **속성**: 오행(목화토금수) + 음양 + 특수 효과(속도·파괴력·기습·제어·회복 등).

### 4.2 창안 프로세스
1. 기반 선택 (기존 비급 or 무에서 창안)
2. 속성 조합 (최대 3개)
3. 세부 커스터마이징 (기술 흐름, 대상, 지속시간)
4. 플레이어 네이밍
5. 참오 완료 → 즉시 사용 + 제자 전수 가능

### 4.3 참오 & 리스크
- 참오 포인트: 서고 + 제자 지혜 + 영약 + 기연.
- 성공률: 참오 경지 + 지혜 – 조합 복잡도.
- 리스크: 실패 시 반동 피해, 내공 폭주, 천벌 기연.

### 4.4 신분별 특화 + 예시
- **자객 추천**: 유혼쾌영검 (음 + 기습 + 이동) — 3연타 + 그림자 이동 + 기습 피해.
- **문주 추천**: 대지생명장 (토 + 양 + 회복 + 범위) — 아군 범위 치유 + 지형 활용.
- 문파 공동 참오 → 고유 비전 무공 완성.

## 5. 전투 시스템 상세 스펙

### 5.1 기본 구조
**그리드 기반 턴제 전술 전투** (헥스/스퀘어 그리드 통합 시스템)

- 턴 순서: 경공 + 속도 기준.
- 액션 포인트(AP) 시스템.
- 지형 효과 강력 (경공으로 장애물 극복, 낙하 공격 등).

### 5.2 전투 유형
- **개인 결투 (1:1)**: 시네마틱 + 관계 드라마 극대화.
- **소규모 교전**: 빠른 전술.
- **대규모 문파전**: 지휘·진형·장수 활약 시스템 (ROTK 스타일).

### 5.3 무공·내공·경공 연동
- 창안 무공: 연계 시스템 + 특수 효과 그대로 적용.
- 내공: 자원 + 리스크(폭주).
- 경공: 이동·회피·기습·추격의 핵심.

### 5.4 관계·신분 연동
- 혈맹/사제: 상호 버프.
- 원한: 추가 피해 + 특수 대사.
- 신분별 가산 (간자 = 은신, 문주 = 지휘 버프).

### 5.5 승리 조건 및 시스템
- 적 전멸 / 목표 달성 / 항복·포로 시스템.
- 대규모: 진형, 지휘 명령, 장수 개인 무공이 전투 흐름을 바꿈.

## 6. 관계·기연·스토리 시스템

### 6.1 관계 본드 시스템 (ROTK 8 스타일)
- 사제지간, 연애/결혼, 혈맹, 라이벌/원한.
- 시간 + 공동 행동 + 선택에 따라 단계 진화.
- 본드가 깊어질수록 전투 버프·특수 기연 발생.
- 배신 이벤트는 극적으로 발생.

### 6.2 기연 시스템
- 매 턴 조건 기반 이벤트 다수 발생.
- 신분별 전용 기연 + 개인 운명 아크.
- 선택지가 스토리·자질·관계·결말에 영구 영향.

### 6.3 스토리 아크 예시
- 복수와 용서
- 승계와 내부 배신
- 금단의 사랑 (정파-사파, 스승-제자)
- 간자 이중생활
- 마교 대침공과 강호 연합

## 7. 문파 경영 및 전략 시스템

- **내정**: 전각 건설, 제자 배치·훈련, 자원·무공 참오.
- **외교**: 동맹·혼담·도전·배신 (ROTK 사절 시스템).
- **전쟁**: 대규모 문파전 + 개인 결투.
- **특수**: 문파 합병, 제자 포로 교환, 황실 개입.

## 8. 유사 게임 분석 및 차별점

### 8.1 주요 유사 게임
- **武侠：开宗立派 (2024)**: 문파 창시 + 무공(스킬) 창안 — 가장 가까움. 하지만 카드 게임 중심.
- **太吾绘卷**: 최고 수준의 기연·관계·샌드박스 시뮬레이션. 하지만 플레이어 문파 창시·대규모 전략은 약함.
- **侠客风云传**: 높은 자유도 + 턴제 관리 + 관계. 하지만 문파 창시·전쟁은 제한적.
- **我的門派** (모바일): 순수 문파 경영. 전략성은 있지만 깊이와 서사 부족.

### 8.2 시장 공백 및 차별점
- 정확히 일치하는 게임 **없음**.
- 우리 게임만의 강점: **무공 창안 + ROTK 스타일 전략 + 신분 전환 + 깊은 기연 드라마**의 완벽 결합.

## 9. 기술적 고려사항 및 확장성

### 9.1 기술 스펙 방향
- 그래픽: 2D/2.5D 아름다운 무협 미학 (산수화 스타일).
- 턴: 월/계절 턴 (경영) + 실시간/턴제 하이브리드 전투.
- 저장본: Ironman + 다중 칸 지원.
- 모드 지원: 캐릭터·기연·무공·시나리오 제작 가능.

### 9.2 PK 스타일 확장 방향
- 추가 시나리오 팩 (북방 침공, 황실 부활, 특정 문파 중심).
- 신규 속성·카테고리·전설 무공 프로젝트.
- “무공 대결” 시스템 (적 무공 분석 → 카운터 참오).

## 10. 예시 플레이 흐름 (종합)

1. **시작**: 막내 제자로 작은 문파 입문.
2. **중반**: 스승 암살 기연 발생 → 복수 위해 적 문파에 간자로 침투.
3. **후반**: 간자 신분으로 공 세워 적 문파 총관 승진 → 본래 문파와 갈등.
4. **결말 분기**:
   - 이중 간자로 살아남아 새로운 문파 창설.
   - 정체 드러나 처형 (비극 결말).
   - 본래 문파로 귀환해 문주 등극 (정파 통일 결말).
