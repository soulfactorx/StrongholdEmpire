# 행동 대화 장면 데이터 형식

경영 화면에서 행동(제자 수련·영약·연회·시설·제자 지도·무공 전수·역할 고유 행동)을 하면, 결과 알림 대신
그 일에 얽힌 인물과 주고받는 짧은 대화 장면이 기연 창으로 뜹니다. 결과(수치 변화)는 장면 아래 【 】 안에 보이고,
선택지를 고르면 작은 여파(유대·도덕 등)가 반영됩니다.

- 파일: `data/scenes/actions/<행동>.json` (하위 폴더도 읽음). 해석기 `scripts/Systems/action_scenes.gd` (`ActionScenes`)
- 설정 [행동 대화 장면]으로 끌 수 있습니다 (`GameSettings.action_scenes`, 기본 켜짐)
- 기연이 기다리거나 다른 장면이 떠 있거나, 행동이 전투·기연으로 이어지면 장면을 띄우지 않고 알림으로 보입니다
- 고르지 않고 화면을 떠났다가 경영 화면으로 돌아오면 그 장면을 다시 띄웁니다

## 행동 id

| id | 행동 | 문맥 |
|---|---|---|
| `train` · `elixir` · `feast` | 제자 수련 · 영약 구매 · 문파 연회 | |
| `facility` | 시설 짓기·확장 | `{detail}` 시설 이름 |
| `disciple_train` · `transmit` | 제자 개별·일괄 수련 · 무공 전수 (제자 명단) | `{disciple}`·`$disciple` 그 제자(일괄 수련이면 "제자들"), `{detail}` 무공 이름 |
| `council` · `envoy` | 문주: 문파 회의 · 사절 파견 | `{target}` 상대 세력, `$target_leader` 그 문주 |
| `department` · `proposal` | 중간관리자: 부서 지정 · 건의 | `{detail}` 부서 이름 |
| `teaching` · `outing` | 막내 제자: 가르침 · 외출 | |
| `job_escort` · `job_search` | 낭인 의뢰: 호위 · 수색 (토벌은 전투) | `{detail}` 의뢰 이름 |
| `intel` · `sabotage` | 간자: 정보 수집 · 사보타주 | `{target}`, `$target_leader` |
| `lie_low` | 자객: 은신 (표적 의뢰는 전투) | |
| `contract` · `fulfill` · `breach` | 용병: 계약 수주 · 이행 · 위반 | `{target}` 의뢰 세력, `$target_leader` |

## 예시

```json
{
  "action": "feast",
  "scenes": [
    { "id": "feast_music", "title": "현악의 밤",
      "if": [ { "type": "season", "in": ["가을"] } ],
      "result": "any",
      "speaker": ["npc_musician", "$narrator"],
      "lines": [ "{speaker}: 좋은 자리에 소리가 빠질 수 없지요.", "칠현금 소리가 밤하늘에 퍼진다." ],
      "choices": [
        { "label": "후하게 사례한다", "message": "금화 -10, 유대 +2",
          "effects": [ { "type": "sect", "field": "gold", "add": -10 }, { "type": "bond", "target": "$speaker", "add": 2 } ] },
        { "label": "박수로 답한다" } ],
      "weight": 1 }
  ]
}
```

## 장면 필드

| 필드 | 설명 |
|---|---|
| `id` | 파일 안에서 겹치지 않는 id. 같은 행동에서 최근 본 장면은 다른 장면이 있으면 피한다 |
| `title` | (선택) 창 제목 "행동 이름 — 장면 제목" |
| `if` | (선택) 조건 목록 — 기연 조건 문법 (`docs/기연_데이터_형식.md`: 계절·역할·문파·관계·성향·플래그 등) |
| `result` | (선택) `any`(기본) · `success` · `fail` — 행동의 성공·실패 |
| `speaker` | 말하는 사람. 명부 인물 id 또는 아래 토큰. 배열이면 앞에서부터 처음 찾은 사람. 아무도 없으면 이 장면은 고르지 않는다 |
| `lines` | 대사·서술 줄. `{speaker}: 대사` 형식이면 그 사람의 말. 말할 사람이 없으면(서술) 따옴표 대사로 바뀐다 |
| `choices` | (선택) 선택지 `{label, message, effects}`. 없으면 [고개를 끄덕인다]. `effects`는 기연 효과 문법, `"target": "$speaker"`는 말한 인물 |
| `weight` | (선택) 뽑힐 상대 확률 (기본 1) |

**말하는 사람 토큰**: `$leader`(우리 문주, 주인공이 문주면 없음) · `$master`(사부) · `$bond`(가장 깊은 인연) ·
`$officer:<직책>`(instructor 교두 · healer 의원 · elder 장로 · steward 총관 · heir 후계자 · leader) · `$disciple`(그 제자, 없으면 아무 제자) ·
`$target_leader`(상대 세력의 문주) · `$counterpart` · `$target` · `$narrator`(서술, 말하는 사람 없음).
이 시나리오에 나오지 않는 인물(`hidden_npcs`)과 주인공 자신은 고르지 않는다.
행동마다 서술(`$narrator`) 장면을 하나 이상 두어, 어느 문파·시나리오에서도 장면이 비지 않게 한다.

**빈칸**: `{player}` 주인공 · `{speaker}` 말하는 사람 · `{sect}` 우리 문파 · `{season}` 계절 · `{target}` 상대 세력 · `{detail}` 시설·무공·부서·의뢰 · `{disciple}` 제자.

## 검증

스모크 테스트 `_test_action_scenes`가 모든 장면 파일을 읽고(형식·조건·효과·말하는 사람 검사), 역할마다 성공·실패 모두에
장면이 있는지, 빈칸이 다 채워지는지, 경영 화면에서 행동하면 대화 창이 뜨고 고르면 여파가 반영되는지 확인합니다.
