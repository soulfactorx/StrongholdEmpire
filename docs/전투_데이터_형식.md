# 전투 데이터 형식

기연에서 이어지는 전투는 `data/combats/` 폴더의 JSON 파일 하나당 하나씩 정의합니다.
전투는 **초식 배치 대결**로 치릅니다 (아래 **초식 배치 대결**). 좌표·지형 필드는 옛 격자 전투와의 호환을 위해 남아 있으며,
대결에서는 줄 순서(목록 순서)와 전장 분위기로만 쓰입니다.
시나리오 전용 전투는 `data/scenarios/<id>/combats/`에 둡니다. 하위 폴더도 읽습니다.
해석기는 `scripts/Systems/combat_library.gd`입니다. 형식이 잘못된 파일은 경고를 남기고 건너뜁니다.

기연의 `combat` 효과에 이 파일의 `id`를 쓰면 전투가 시작됩니다 (`docs/기연_데이터_형식.md`).
비무·야습 도적처럼 코드로 만드는 전투(`CombatManager.COMBAT_IDS`)와 id가 겹치면 안 됩니다.

## 예시

```json
{
  "id": "arc_revenge_duel_allied",
  "title": "결투 — 귀영과 수하들",
  "player_position": [3, 5],
  "enemies": [
    { "npc": "npc_shadow_blade", "position": [12, 5] },
    { "npc": "npc_bandit", "position": [13, 3], "name": "귀영의 수하" }
  ],
  "allies": [ { "npc": "npc_rival", "position": [3, 3] } ],
  "terrain": { "FOREST": [[6, 2], [6, 3]], "HIGH": [[4, 8]] },
  "relationship_target": "npc_shadow_blade",
  "enemy_hp_scale": 0.9,
  "rewards": { "experience": 40, "reputation": 3 },
  "defeat_penalty": { "reputation": 3, "injury_ratio": 0.3 },
  "victory_flag": "arc_revenge_won",
  "defeat_flag": "arc_revenge_lost"
}
```

## 필드

| 필드 | 설명 |
|---|---|
| `id`, `title` | 필수. 제목은 전투 화면 상단에 표시 |
| `enemies` | 필수. `{ npc, position, name?, stats? }` 목록. `npc`는 명부 id, `scaling`이 있는 인물은 플레이어 레벨에 맞춰 강해집니다 |
| `allies` | (선택) 함께 싸우는 인물. 우리 줄에서 목록 순서대로 주인공 앞에 섭니다. 쓰러져도 문파 제자는 줄지 않습니다 |
| `disciple_allies` | (선택) 문파 제자가 합류할 자리 `[[x, y], ...]`. 최대 `DEFENSE_ALLY_COUNT`명, 쓰러지면 문파 제자가 줄어듭니다 |
| `player_position` | (선택, 호환용) 주인공 칸. 대결에서는 쓰지 않음 |
| `blocked` | (선택, 호환용) 막힌 칸 |
| `terrain` | (선택, 호환용) `FOREST`(수풀) · `WATER`(물) · `HIGH`(고지)별 칸 목록 |
| `relationship_target` | (선택) 전투 후 유대가 바뀌는 관계 대상 (보상·손실의 `bond`) |
| `enemy_hp_scale`, `enemy_damage_scale` | (선택) 적 체력·피해 배율. 강한 우두머리나 여러 졸개를 둘 때 낮춥니다 |
| `rewards` | 승리 보상: `experience`, `gold`, `reputation`, `strength`, `bond` |
| `defeat_penalty` | 패배 손실: `gold`, `reputation`, `injury_ratio`(남는 내공 비율), `bond`. 후퇴는 절반 |
| `victory_flag` | 이기면 켜지는 스토리 플래그 |
| `defeat_flag` | 지거나 후퇴하면 켜지는 스토리 플래그. 스토리 아크의 갈림길에 씁니다 |
| `max_bouts` | (선택) 한 대결의 합 수. 기본 `DUEL_MAX_BOUTS`(4). 넘으면 체력 비율이 낮은 쪽이 물러난다 |
| `objective` | (선택) 전투 목표. 생략하면 적을 모두 쓰러뜨리면 승리 (아래 **목표·날씨·전장·증원**) |
| `weather` | (선택) 날씨·시간: `clear` · `night` · `rain` · `fog` · `snow` |
| `battlefield` | (선택) 전장 모양: `plain` · `forest` · `river` · `mountain` · `town` · `snow` · `courtyard`. `terrain`·`blocked`가 없으면 이 모양으로 지형을 만든다 (판마다 다름) |
| `reinforcements` | (선택) 적 증원 `[{ round, npc, position, name?, stats? }]` — 상대 줄 맨 뒤에 선다 (`round`는 호환용, 2 이상) |

- 좌표는 `[x, y]`, 가로 16칸(0~15) × 세로 10칸(0~9) 안이어야 합니다 (호환용 검증).
- `stats`는 명부 능력치에 더하는 값입니다: `strength`, `agility`, `wisdom`, `charisma`, `internal_energy_max`
  (예: 병든 스승은 `{ "strength": -5, "internal_energy_max": -100 }`)
- 같은 졸개 인물을 여럿 두면 자동으로 서로 다른 id가 붙습니다. `name`으로 구별되는 이름을 주세요.

## 목표·날씨·전장·증원 (`scripts/Combat/battlefield.gd`)

```json
"objective": { "type": "survive", "rounds": 4 },
"weather": "night", "battlefield": "town",
"reinforcements": [{ "round": 3, "npc": "npc_cheonma_cultist", "position": [15, 5], "name": "혈교도 무" }]
```

| 목표 `type` | 필드 | 승패 |
|---|---|---|
| `defeat_all` | – | 상대 줄을 모두 쓰러뜨리거나 물러나게 하면 승리 (기본) |
| `defeat_target` | `target`: 적의 npc id | 우두머리와 바로 겨룬다. 나머지 적은 호위로, 하나마다 우두머리 체력 +15%. 우두머리만 이기면 승리 |
| `survive` | `rounds` | 주인공이 선봉으로 나서 그 합 수를 버티면 승리 (상대 줄을 다 이겨도 승리) |
| `escape` | `tiles`(선택, 호환용) | 주인공이 선봉으로 나서 공격을 `DUEL_ESCAPE_EVADES`(3)번 흘리면 승리 |
| `protect` | `target`: 아군의 npc id | 그 아군은 줄에 서지 않는다. 우리 쪽이 대결에서 질 때마다 체력 40%(`DUEL_WARD_HIT`)를 잃고, 쓰러지면 패배 |

| 날씨 | 영향 |
|---|---|
| `night` 밤 | 회피 속도 +1 |
| `rain` 비 | 화 초식 피해 -30%, 수 초식 피해 +20% |
| `fog` 안개 | 상대 배치가 한 단계 덜 보임 |
| `snow` 눈 | 강공 속도 -1 |

- 전투 화면 위에 목표·전장·날씨·증원을 보이고, 배경은 그 지역의 그림을 쓴다.
- 코드로 만드는 전투(야습 도적·토벌 의뢰·표적 의뢰·추격전·침공·비무)는 판마다 지역에 맞는 전장과 계절 날씨를 고르고,
  토벌 의뢰는 우두머리 토벌·상단 호위·모두 격파 가운데 하나, 추격전은 절반 확률로 탈출전이 된다 (`CombatManager.varied`, 스모크 테스트에서는 끔).

## 초식 배치 대결 (`scripts/Combat/duel_*.gd`)

| 파일 | 하는 일 |
|---|---|
| `duel_card.gd` (`DuelCard`) | 초식 카드: 기본 동작 5가지, 무공 → 초식 바꾸기, 숙련 단계, 합격 |
| `duel_rules.gd` (`DuelRules`) | 한 칸 판정: 내공·기세·기절 확인, 상성, 속도 순서, 반격, 운기, 기세 이동, 날씨, 회심 |
| `duel_ai.gd` (`DuelAI`) | 배치 AI: 성향 가중치, 지난 합 맞받기, 절초·운기 판단 |
| `duel_engine.gd` (`DuelEngine`) | 한 판: 연전 줄, 합 진행, 목표, 정보(지혜·버릇), 숙련 기록, 인연. 화면 없이 테스트·시뮬레이터가 쓴다 |
| `duel_controller.gd` | 전투 화면 (`scenes/Combat/combat_scene.tscn`) |

- **칸 수**: Lv.1 3칸, Lv.5·10·15에 한 칸씩 (최대 6).
- **유형**: 강공(속도 1) · 속공(3) · 막기(2) · 회피(3) · 술(2) · 기(0). 같은 칸에서는 속도 × 10 + 신법이 높은 쪽이 먼저 친다.
- **상성**: 강공 > 막기 > 속공 > 강공. 회피는 자기보다 느린 강공·속공을 흘리고(빠르면 스침 50%), 술에 약하다.
  술은 회피를 읽고 막기를 60%로 뚫지만 속공에 끊긴다(50%). 기는 무방비(받는 피해 130%). 빈 칸·헛손질은 빈틈(120%).
- **피해** = (초식 위력 × (1 + 숙련 단계 × 10%) + 무력 × 0.8) × 오행 × 날씨 × (1 + 기세 × 5%) × 적 배율 × 인연 ÷ 가호 × 상성 × 회심.
- **기세**(0~5): 한 칸에서 더 큰 피해를 준 쪽 +1, 진 쪽 -1. 운기 +1. 새 대결마다 0에서 시작.
- **무공 → 초식**: 무공의 `card_type`(`STRIKE`·`QUICK`·`GUARD`·`EVADE`·`FOCUS`·`TRICK`)이 있으면 그 유형,
  없으면 회복 → 기, 암기·사거리 3 이상·제어 → 술, 경공 → 회피, 빠름·각법·지법 → 속공, 파괴력·행동력 3 이상·피해 22 이상 → 강공, 그 밖은 속공.
  위력 32 이상의 공격 초식은 기세 2, 45 이상은 기세 3이 드는 절초다.
- **효과**: 제어 → 기절(상대 다음 칸이 막힘, 3칸 동안 다시 기절하지 않음), 파괴력 → 막기 무시, 기습 → 다치지 않은 상대에게 1.5배, 강화 → 맞히면 기세 +1 더.
- **줄**: 아군이 앞, 주인공이 대장(첫 합 전에 선봉으로 바꿀 수 있음, 탈출·버티기 목표는 처음에 선봉). 동료는 합이 끝났을 때 체력 30% 미만이면 물러난다.
- **정보**: 지혜 13 이상 첫 칸 유형, 19 이상 모든 칸 유형, 25 이상 초식 이름 (안개는 한 단계 덜).
  상대의 첫 칸 유형은 `GameManager.duel_memory`에 인물별로 쌓여 다음에 "버릇"으로 보인다 (저장됨).
- **숙련**: 무공 초식을 쓸 때마다 `GameManager.art_mastery`에 쌓이고 8번마다 한 단계 (최대 3단, 저장됨).
- **인연**: 원한·연적 등과 겨루면 그 인연의 피해 배율, 주인공은 줄에 서 있는 깊은 인연만큼 가호.
  유대 `DUEL_COMBO_BOND`(40) 이상의 사제·혈맹·연인·배우자·벗·제자가 줄에 서 있으면 주인공 손패에 그 동료의 **합격**(강공, 막기 무시, 기세 2) 초식이 든다.
- 수치는 `GameBalance`의 `DUEL_*`에 있다. 바꾸면 밸런스 시뮬레이터(`balance_sim.gd -- combat`)로 결과를 확인하고 구현 계획 M9-10에 갱신한다.

## 검증

스모크 테스트의 `_test_combat_library`가 모든 전투 파일을 불러와 구성을 만들고, 좌표가 범위 안에 있는지 확인합니다.
대결 규칙은 `_test_duel_rules`·`_test_duel_cards_and_ai`·`_test_duel_engine`·`_test_duel_screen`이 시험합니다.
