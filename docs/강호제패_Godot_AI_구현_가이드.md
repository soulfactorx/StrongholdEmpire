# 강호제패 (强胡制覇) - Godot 4 + AI 코드 생성 완전 가이드 문서

**목적**: 이 문서를 AI(Claude, GPT, Grok 등)에게 제공하여 **Godot 4**로 게임을 단계적으로 제작할 수 있게 하는 종합 프롬프트 문서입니다.  
**엔진**: Godot 4.3 이상 (GDScript 중심)  
**버전**: 1.1 (2026년 6월 24일)  
**라이선스**: 자유 사용 및 수정 가능

---

## 1. 게임 전체 개요 (AI에게 제공할 핵심 컨셉)

**게임 제목**: 강호제패 (Jianghu Conquest)  
**장르**: 무협 전략 시뮬레이션 RPG (턴제 경영 + 그리드 전술 전투)  
**모티브**: Romance of the Three Kingdoms 8 Remake 스타일 + 무협 세계관

### 핵심 철학
- 모든 캐릭터가 주인공이 될 수 있다 (문주, 막내 제자, 간자, 자객, 낭인 등).
- 플레이어가 **직접 무공을 창안**하고 명명한다.
- 깊은 관계 본드 시스템 (사제, 연애, 배신, 혈맹).
- 기연(조건 기반 이벤트)이 풍부한 샌드박스.
- 전략(문파 경영) + 개인 드라마(복수, 사랑, 성장)가 결합.

**주요 시스템**:
- 동적 신분 전환 시스템
- 무공 창안 시스템 (데이터 기반)
- 그리드 기반 턴제 전술 전투 (경공·내공·관계 연동)
- 기연 + 관계 진화 시스템
- 문파 경영 + 대규모 전쟁

## 2. 추천 기술 스택 (고정)

- **엔진**: Godot 4.3+
- **언어**: GDScript (기본 90%) + C# (필요 시 성능 부분)
- **그래픽**: 2D (TileMap + Sprite2D)
- **데이터 관리**: Godot `Resource` + JSON
- **UI**: Godot Control 노드 + Theme
- **상태 관리**: State Machine 패턴 적극 사용
- **버전 관리**: Git

**왜 Godot인가?**
- 전략 시뮬 + RPG 하이브리드에 최적
- 리소스 시스템으로 무공·캐릭터·기연을 데이터로 관리하기 좋음
- 그리드 전투 구현이 상대적으로 수월
- 완전 무료 + 가벼움

## 3. Godot 프로젝트 구조 (권장)

```
강호제패/
├── addons/                  # 플러그인 (Dialogue Manager 등)
├── scenes/                  # 씬 파일
│   ├── UI/                  # 관리 화면, 메뉴
│   ├── Combat/              # 전투 관련 씬
│   ├── World/               # 맵, 문파 본거지
│   └── Characters/          # 캐릭터 프리팹
├── scripts/                 # GDScript
│   ├── Systems/             # 핵심 시스템 (Combat, Relationship, Event 등)
│   ├── Resources/           # Resource 스크립트
│   ├── Characters/          # 캐릭터 로직
│   └── UI/                  # UI 컨트롤러
├── resources/               # .tres 파일 (데이터)
│   ├── MartialArts/         # 창안 무공 데이터
│   ├── Characters/          # 캐릭터 데이터
│   ├── Events/              # 기연 데이터
│   └── Sects/               # 문파 데이터
├── data/                    # JSON 파일 (대량 데이터)
├── assets/                  # 그래픽, 사운드
└── project.godot
```

## 4. 핵심 시스템 구현 가이드 (AI 프롬프트용)

### 4.1 무공 창안 시스템 (최우선 구현)

**요구사항**:
- Resource 기반으로 무공 정의
- 카테고리 + 오행 + 음양 + 특수 효과 조합
- 참오 시스템 (턴 소모, 성공률, 리스크)
- 신분별 특화
- 전투에서 연계 및 효과 적용

**AI에게 요청할 때 사용할 프롬프트 예시**:
```
Godot 4 GDScript로 무공 창안 시스템을 Resource 기반으로 구현해줘.
- MartialArt.gd Resource 클래스 만들기
- 카테고리(enum): Sword, Palm, Fist 등
- 속성: FiveElements (Wood, Fire...), YinYang
- 특수 효과 배열
- 참오 비용, 성공률 계산 함수 포함
- 예시 무공 3개 (유혼쾌영검, 대지생명장 등) 데이터 생성
```

### 4.2 전투 시스템 (그리드 턴제)

**요구사항**:
- Grid 기반 턴제 전술
- 경공 이동 + 내공 관리
- 창안 무공 연계 시스템
- 관계 본드 가산 적용
- 1:1 결투와 대규모 전투 모두 지원

**AI 프롬프트 예시**:
```
Godot 4에서 그리드 기반 턴제 전술 전투 시스템을 만들어줘.
- HexGrid 또는 SquareGrid 사용
- Character 클래스 (stats, current_martial_art, internal_energy)
- TurnManager (턴 순서 계산, AP 시스템)
- MartialArt 사용 시 효과 적용 (데미지, 이동, 상태이상)
- 관계 시스템과 연동 (혈맹이면 버프)
- 간단한 예시 전투 시나리오 포함
```

### 4.3 신분 및 관계 시스템

**요구사항**:
- State Machine으로 신분 관리 (Leader, Disciple, Spy 등)
- 관계 본드 (사제, 연애, 원한) 수치 및 진화
- 신분 전환 시 자질·이벤트 변화

**AI 프롬프트 예시**:
```
Godot에서 신분 전환 시스템을 State Machine으로 구현해줘.
RoleState.gd (Leader, YoungDisciple, Spy, Assassin 등)
RelationshipSystem.gd (bond strength, type, evolution logic)
신분 변경 시 이벤트 발생 및 자질 보정 포함
```

### 4.4 기연(이벤트) 시스템

- 조건 기반 이벤트 트리거
- 선택지 → 결과 분기
- 관계·자질·무공에 영향

## 5. 단계별 개발 계획 (AI와 함께 진행 추천)

### Phase 1: 기반 구축 (1~2주)
1. Godot 프로젝트 생성 + 기본 폴더 구조
2. Character Resource + 기본 자질 시스템
3. 간단한 턴제 내정 화면 (문파 자원 관리)
4. 기본 그리드 이동 데모

### Phase 2: 핵심 시스템 (3~6주)
1. 무공 창안 시스템 (Resource + 참오 로직)
2. 전투 시스템 베이스 (그리드 + 턴 관리)
3. 관계 본드 시스템
4. 기본 기연 이벤트 시스템

### Phase 3: 콘텐츠 확장 (7~12주)
1. 신분 전환 로직 + 다양한 신분별 이벤트
2. 대규모 문파전 지휘 시스템
3. 세대 전승·후대 기능
4. 다양한 시나리오 + 결말 분기

### Phase 4: 폴리싱
- UI/UX 개선
- 그래픽·사운드 연동
- 밸런스 조정
- 모드 지원 준비

## 6. AI 코드 생성을 위한 효과적인 프롬프트 가이드

### 좋은 프롬프트 작성 원칙
1. **구체적으로 명시**: "Godot 4 GDScript로", "Resource 클래스로", "State Machine 패턴 사용"
2. **시스템 간 연동 명시**: "무공 시스템과 전투 시스템을 연동해서..."
3. **예시 제공**: "유혼쾌영검 같은 예시 무공을 포함해서"
4. **점진적 요청**: 한 번에 전체를 만들지 말고, 작은 단위로 요청 후 수정
5. **리팩토링 요청**: "위 코드를 더 모듈러하게 리팩토링해줘"

### 추천 작업 순서 (AI에게 단계적으로 요청)
1. 먼저 **Resource 클래스**들부터 만들기 (MartialArt, Character, Event)
2. 그 다음 **시스템 매니저** (CombatManager, RelationshipManager, EventManager)
3. UI와 연동
4. 테스트용 간단한 씬 제작 요청

## 7. 전체 게임 디자인 요약 (AI 컨텍스트용)

(이전 문서의 주요 내용을 간결하게 요약)

- **시대**: 천하대란기 (권력 공백 + 문파 난립)

- **목표**: 문파를 키워 강호 제패 or 개인 전설 완성
