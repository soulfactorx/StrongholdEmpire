# 전투 다양화 설계 — 초식 배치 대결 위에서

> 구현됨 (구현 계획 M9-11). 데이터 필드는 `docs/전투_데이터_형식.md`의 **전투 다양화**를 따른다.
> 설계와 달라진 점: 포위의 적은 한꺼번에 셋까지, 졸개는 체력·피해가 약하다, 칸 수가 모자라 비는 칸은 빈틈이 아니다,
> 인연의 개입은 체력 25% 회복과 기세 +2, 사건 선택의 효과는 전투가 끝난 뒤 반영된다.

초식 배치 대결(칸에 초식을 놓고 첫 칸부터 맞부딪침)의 핵심 규칙은 그대로 두고,
**전투마다 "무엇을 겨루는가"를 바꿔** 같은 판단이 되풀이되지 않게 한다.

- 지금: 모든 전투가 "상대 체력을 0으로" 하는 연전이다. 목표(우두머리·버티기·탈출·호위)와 날씨가 조금 바꿀 뿐이다.
- 바꿀 것: 전투 하나를 다섯 겹으로 조립한다. 겹마다 몇 가지씩만 있어도 조합이 많아진다.

| 겹 | 묻는 것 | 예 |
|---|---|---|
| 1. 형식 `format` | 몇 대 몇, 어떻게 맞서나 | 연전 · 포위 · 진형 · 추격 · 잠입 · 대치 · 비무대회 |
| 2. 목표 `objective` | 무엇을 하면 이기나 | 격파 · 우두머리 · 버티기 · 탈출 · 호위 · 생포 · 시간 안에 |
| 3. 전장 `stage` | 이곳의 고유 규칙 | 외나무다리 · 지붕 위 · 배 위 · 불타는 장원 · 대숲 · 비무대 |
| 4. 조건 `conditions` | 내 쪽 제약·상대 쪽 특성 | 중독 · 맨손 · 부상 · 정정당당 · 광폭 · 독무 |
| 5. 사건 `events` | 싸우는 중에 생기는 이야기 | 증원 · 배신 · 인연의 개입 · 설득 · 단계 전환 |

전투 설계자는 이야기에 맞게 겹을 고르고, 코드 전투(의뢰·야습 등)는 판마다 무작위로 조합한다.
아래 수치는 첫 제안이며 `GameBalance`의 `DUEL_*`로 둔다.

---

## 1. 형식 (`format`)

### 1-1. 연전 `duel` — 지금 방식
양쪽 줄에서 한 사람씩 나와 1대1. 선봉·대장 순서 선택. 비무·원수와의 결투·장문인 시험에 쓴다.

### 1-2. 포위 `siege` — 1대다
주인공(과 동료 한둘)이 졸개 여럿에게 둘러싸인다.
- 칸마다 **적 모두가** 초식을 낸다. 졸개는 칸이 2개뿐이라 앞 2칸에 몰린다(우두머리는 보통 칸 수).
- 내 칸에는 초식과 함께 **겨룰 상대**를 고른다(칸을 누르면 상대 고르기). 고른 상대와는 평소처럼 맞부딪치고, 나머지 적의 공격은 그 칸의 내 초식으로 받는다.
  - 막기: 그 칸의 속공 모두를 받아치고, 강공은 모두 못 막는다.
  - 회피: 자기보다 느린 공격을 모두 흘린다.
  - 그 밖의 유형: 고른 상대 말고는 빈틈처럼 맞는다.
- 새 기본 동작 **휩쓸기**(강공, 속도 1, 위력 낮음, 내공 10): 그 칸의 적 모두를 친다(고른 상대는 온전히, 나머지는 60%).
- **포위 압박**: 살아 있는 적이 셋 이상이면 칸마다 주인공 기세 +1. 혼자 여럿을 상대할수록 절초가 빨리 열린다(무협의 맛).
- 판단 거리: 누구부터 끊을지, 어느 칸을 막기·회피로 버틸지, 휩쓸기를 언제 쓸지.

### 1-3. 진형 `formation` — 다대다
2~3명 대 2~3명. 앞줄과 뒷줄이 있다.
- 앞줄이 서 있는 동안 뒷줄은 **술**(암기·독)로만 칠 수 있다. 뒷줄도 술로만 친다.
- 휴대폰에서 세 명 몫을 다 놓기 번거로우므로 **주인공만 칸을 직접 놓고**, 동료는 지시 칩 하나만 고른다:
  - 공세: 강공·속공 위주로 놓는다
  - 수비: 막기·회피 위주로 놓는다
  - 엄호: 주인공이 겨루는 상대에게 막기를 겹친다
  - 보조: 운기·회복으로 기세를 모아 합격을 노린다
- 협동 규칙:
  - **협공**: 같은 칸에서 둘이 같은 적을 치면 두 번째 타격 +30%
  - **엄호**: 막기를 놓은 동료가 옆 사람이 받을 피해의 절반을 대신 받는다
  - **합격**: 지금과 같다. 진형에서는 두 사람이 같은 칸을 쓴다
- 판단 거리: 앞줄을 먼저 무너뜨릴지, 술로 뒷줄 의원을 노릴지.

### 1-4. 추격 `chase` — 거리 겨루기
쫓거나 쫓기는 싸움. 체력 대신 **거리 게이지**(0~10, 시작 5)가 승패를 가른다.
- 쫓기는 쪽이 회피·속공으로 이기면 거리 +2, 맞으면 거리 -1.
- 쫓는 쪽이 강공·술로 맞히면 거리 -2.
- 운기를 놓으면 그 칸에서 거리 -1 (멈춰 섰으므로).
- 거리 10에 닿으면 놓침(도주 성공), 0이면 붙잡힘. 붙잡히면 그 자리에서 연전으로 바뀐다.
- 날씨: 밤·안개는 쫓기는 쪽의 회피 +1. 비는 강공 -1.
- 쓰임: 지금의 `escape` 목표를 이 형식으로 바꾼다(추격대·처형장 탈출·연인과의 도주).

### 1-5. 잠입 `stealth` — 발각 게이지
들키기 전에 끝내는 싸움.
- 상대는 첫 합을 준비하지 못한다: **첫 합의 상대 배치는 막기·운기만**(경계 전). 내 첫 칸 기습은 2배.
- **발각 게이지**(0~5): 강공을 낼 때마다 +1(소리가 난다), 상대가 막기로 버틴 칸마다 +1. 속공·술·회피는 조용하다.
- 5가 되면 경보: 숨어 있던 증원이 상대 줄에 붙고, 기습 가산이 사라진다.
- 목표는 보통 우두머리(표적) 하나. 판단 거리: 강공 없이 끝낼 수 있나, 들킬 각오로 몰아칠까.
- 쓰임: 자객 표적 의뢰, 지하 감옥 구출, 간자 임무.

### 1-6. 대치 `standoff` — 기세 싸움
칼을 뽑기 전에 기세로 겨룬다. 피해가 없다.
- 칸마다 이긴 쪽이 기세 +1, 진 쪽 -1. 운기는 +1. 먼저 기세 5에 닿는 쪽이 이긴다.
- 지혜가 높을수록 상대 배치가 더 보이고, 매력이 높으면 첫 기세 +1(위압).
- 이기면 상대가 물러나거나(싸움 없이 해결) 이어지는 연전에서 기세 3으로 시작한다. 지면 반대.
- 쓰임: 산문 앞의 협상, 정사 회담, 협박, 고수끼리 서로를 재는 장면. 짧고(2~3합) 이야기가 진한 전투.

### 1-7. 비무대회 `tournament` — 연속 1대1
대진표에 따라 3~4번 연달아 겨룬다.
- 판 사이 회복은 체력 30%·내공 50%만. 다음 상대의 지난 경기를 **관전**해 버릇이 미리 보인다.
- 같은 무공 초식을 연달아 쓰면 다음 상대가 읽는다(그 유형을 맞받는 확률 +20%).
- 우승·준우승·탈락이 기연 분기가 된다. 무림대회·문파 내 승계 비무에 쓴다.

## 2. 목표 (`objective`) — 지금 다섯 가지에 더할 것

| 목표 | 승패 | 바뀌는 판단 |
|---|---|---|
| `capture` 생포 | 상대 체력을 20% 아래로 만든 뒤 막기·점혈(기절)로 한 칸을 이기면 생포. 체력 0이 되면 실패(죽임) | 세게 치면 안 된다. 마지막에 힘을 빼는 배치 |
| `timed` 시간 안에 | N합 안에 이겨야 한다(구원·불 끄기 전) | 운기·막기를 줄이고 몰아치기 |
| `endure_blows` 버텨 내기 | 주인공이 받은 피해 합계가 N 미만으로 M합 버티기(시험) | 회피·막기의 가치가 올라간다 |
| `disarm` 무기 떨구기 | 상대의 절초 칸을 막기로 받아치거나 회피로 흘려 3번 무산시키기 | 상대 절초 타이밍 읽기(버릇·지혜) |
| `hold_line` 진지 사수 | 진형전에서 앞줄이 한 명이라도 서 있는 채 N합 | 엄호·수비 지시 |

## 3. 전장 (`stage`) — 곳마다 고유 규칙 하나

지금의 `battlefield`(배경 모양)를 넓혀 **규칙 하나씩**을 붙인다. 규칙은 짧고 화면 위에 한 줄로 보인다.

| 전장 | 규칙 |
|---|---|
| 외나무다리 | 회피 불가(헛디딤 → 빈틈). 대신 강공에 맞으면 물에 빠질 위험(체력 20% 아래면 즉시 패배) |
| 지붕 위 | 회피·속공 속도 +1, 강공 -1 |
| 배 위 | 칸마다 흔들림: 짝수 칸은 강공 위력 -30% |
| 불타는 장원 | 합마다 양쪽 체력 -5%, 운기 불가(연기). 짧게 끝내야 한다 |
| 대숲 | 술 +30%, 상대 배치가 한 단계 덜 보임 |
| 비무대 | 술(암기·독) 금지, 장외(체력 비율 20% 아래로 밀리면 패배) |
| 설원·빙판 | 지금의 눈: 강공 속도 -1, 회피에 맞으면 미끄러짐(다음 칸 속도 -1) |
| 좁은 골목 | 포위 형식에서 한 칸에 적 둘까지만 공격 |
| 사당·묘지(밤) | 첫 합에 양쪽 모두 상대 배치가 안 보임 |

코드 전투는 지역의 전장 모양에서 이 규칙을 하나 고른다(`CombatManager.varied`).

## 4. 조건 (`conditions`) — 내 쪽 제약, 상대 쪽 특성

전투마다 0~2개. 이야기의 처지를 전투 규칙으로 옮긴다.

**우리 쪽 처지**
- `poisoned` 중독: 합마다 내공 -10. 운기의 내공 회복 절반
- `unarmed` 맨손: 무공 초식 중 검법·도법을 쓸 수 없다(권각·지법·경공만)
- `wounded` 부상: 칸 -1, 체력 70%로 시작
- `exhausted` 지침: 내공 50%로 시작
- `honor` 정정당당: 술 금지, 빈 칸 금지(빈틈이 있으면 겨룰 수 없다)

**상대 특성 (우두머리 패턴)**
- `enrage` 광폭: 체력 50% 아래가 되면 칸 +1, 기세 +2, 막기를 안 쓴다
- `telegraph` 예고 절초: 3합마다 절초를 마지막 칸에 놓는다. 화면에 "다음 합 마지막 칸: 천마해체대법" — 회피·막기로 받을 준비를 하게 한다
- `poison_mist` 독무: 이 상대와 겨루는 동안 운기 칸은 피해를 받는다
- `iron_body` 금강불괴: 속공 피해 절반, 강공·술은 그대로
- `mirror` 모방: 내가 지난 합에 낸 배치를 그대로 따라 낸다(버릇 읽기의 역이용)
- `two_phase` 단계 전환: 체력 0이 되면 대사와 함께 체력 60%로 다시 일어나고, 초식 구성이 바뀐다(최종 보스)

## 5. 사건 (`events`) — 싸우는 중의 이야기

합 사이에 끼어드는 짧은 장면. 선택지가 있으면 다음 합 배치 전에 고른다.

| 사건 | 발동 | 내용 |
|---|---|---|
| `reinforce` 증원 | N합째 | 지금과 같다(상대 줄에 붙음) |
| `betrayal` 배신 | N합째 또는 조건 | 우리 줄의 한 사람이 상대 줄로 넘어간다(유대가 낮거나 플래그) |
| `bond_intervene` 인연의 개입 | 주인공 체력 30% 아래 | 유대 높은 인물이 뛰어들어 한 합을 대신 받거나 합격을 연다. 대사 |
| `parley` 설득 | 상대 체력 50% 아래 | 선택지: 설득(매력 판정, 성공하면 상대가 물러나고 유대·도덕 변화) / 끝까지 싸운다 |
| `choice_duel` 결단 | N합째 | 선택지: "목숨을 건다"(체력 -30%, 기세 최대) / "물러선다"(후퇴, 손실 절반) / "버틴다" |
| `phase_line` 대사 | 조건 | 보스의 대사·상대의 동요(버릇이 바뀜) |

사건의 결과는 기연과 같은 효과 문법(`flag`·`bond`·`morality` 등)으로 적는다.

## 6. 데이터 형식 (제안)

```json
{
  "id": "s1_bridge_pursuit",
  "title": "외나무다리 — 혈영의 추격",
  "format": "chase",
  "objective": { "type": "escape", "distance": 10 },
  "stage": "bridge",
  "weather": "night",
  "conditions": ["wounded"],
  "enemies": [ { "npc": "npc_blood_shadow", "traits": ["telegraph"] } ],
  "allies": [ { "npc": "npc_yeon_sohwa", "order": "guard" } ],
  "events": [
    { "type": "bond_intervene", "npc": "npc_yeon_sohwa", "when": { "player_hp_below": 0.3 },
      "lines": ["연소화: 먼저 가요! 여긴 제가 막을게요."] },
    { "type": "parley", "when": { "enemy_hp_below": 0.5 }, "choices": [ ... ] }
  ]
}
```

- 없는 필드는 지금과 같게(연전, 격파, 전장 규칙 없음) 읽어 기존 전투 데이터가 그대로 돈다.
- 검증기(`CombatLibrary.validate_combat_dict`)가 형식·목표 짝(예: `distance`는 `chase`에만)을 확인한다.

## 7. 지루하지 않게 하는 장치 (형식 밖)

- **상대의 성격**: 직업별 배치 성향을 나눈다 — 검객(속공·회피), 권사(강공·막기), 암기수(술), 독공(술·독무), 도사(운기·회복), 졸개(무작위·칸 2). 같은 형식이라도 상대가 다르면 답이 다르다.
- **전투에서 배우기**: 상대가 펼친 절초를 회피·막기로 받아 내면 `observed_arts`에 기록되고, 장경각에서 그 유형을 이기는 무공을 참오할 때 가산(지금의 분석과 이음).
- **평가와 도전**: 끝나면 등급(완승·신승·참패)과 짧은 평. 전투마다 선택 도전 하나("3합 안에", "피해 30 이하", "술 없이")를 이루면 명성·깨달음.
- **연출**: 절초·합격·상성 승리 칸에서 카드 뒤집기와 큰 글씨 효과음. 결과만 보기는 그대로.
- **흐름 규칙(설계 지침)**:
  - 한 장(시나리오)에서 같은 형식이 세 번 연달아 나오지 않게 한다.
  - 짧은 전투(대치·잠입, 1~2분)와 긴 전투(진형·비무대회, 4~6분)를 섞는다.
  - 큰 전투 앞에는 그 형식의 작은 전투를 먼저 둔다(배우는 전투 → 시험 전투).
  - 새 형식이 처음 나올 때 한 번 규칙 소개 장면(기능 단계 개방 `FeatureGate`처럼).

## 9. 구현 순서 (제안)

판정의 중심(`DuelRules.resolve_slot`)을 "두 사람"에서 "여러 사람, 대상 있음"으로 넓히는 것이 큰 일이고, 나머지는 그 위에 얹는다.

1. **전장·조건·사건 겹** — 지금 엔진에 바로 얹힌다. `stage`·`conditions`·`events` 필드, 보스 패턴(광폭·예고·단계 전환), 생포·시간 안에 목표, 평가·도전. 형식은 연전 그대로
2. **대치·추격·잠입 형식** — 1대1 판정을 그대로 쓰고 게이지만 다르다. 엔진에 형식별 판정기(`DuelFormat`)를 둔다
3. **포위 형식** — `resolve_slot`을 여러 사람으로. 칸마다 대상 고르기 화면, 휩쓸기
4. **진형 형식** — 앞·뒷줄, 동료 지시 칩, 협공·엄호
5. **비무대회** — 연속 대결·관전·대진표 화면, 무림대회 기연
6. 기존 전투(8절)와 메인 시나리오 전투에 형식을 붙이고, 형식마다 처음 나올 때 소개 장면

각 단계마다:
- 스모크 테스트: 형식·목표·전장·조건·사건 판정 단위 시험, 데이터 검증, 화면 조작(터치만으로)
- 밸런스 시뮬레이터: 형식별 승률·남은 체력·합 수·전투 시간(합 수 × 칸)을 재어 `구현_계획.md`에 남긴다
- 목표치: 예상 경지에서 승률 65~85%, 짧은 전투 2~4합, 긴 전투 8~14합
