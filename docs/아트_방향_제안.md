# 아트 방향 제안

**상태**: 제안 (확정 대기)
**작성일**: 2026년 10월 17일
**전제**: 모든 플랫폼 대상, 우선순위는 모바일 → 웹 → PC(Windows) → Mac → Switch → PlayStation → Xbox

---

## 1. 결론: 수묵담채(水墨淡彩) + 장기말 토큰 전투

화선지 위에 먹으로 그리고 옅은 색을 더한 **수묵담채 일러스트**를 기본 화풍으로 하고,
전투는 **초상 토큰(장기말)을 지도 위에서 움직이는 보드게임식 표현**으로 만든다.

| 요소 | 표현 |
|---|---|
| 배경 | 산수화 일러스트. 여백을 넓게 두고 UI를 그 여백에 얹는다 |
| 인물 | 먹선 + 2~3색 담채 반신 초상. 정적인 그림, 핵심 인물만 표정 1~2종 추가 |
| 전투 | 화선지 지도 위의 원형 초상 토큰. 이동은 미끄러지는 연출, 타격은 먹 번짐 효과 |
| 지형 | 먹 붓터치 질감 타일: 수풀(점묘), 물(먹 물결선), 고지(준법 바위), 벽(담장) |
| UI | 종이 질감 패널, 먹 테두리, 주홍 낙관(도장) 모티브 버튼, 단색 아이콘 |

---

## 2. 왜 이 방향인가

1. **기획과 맞는다**
   디자인 문서 9.1절이 "2D/2.5D 아름다운 무협 미학 (산수화 스타일)"을 명시한다.
   무공 창조, 기연, 문파라는 소재 자체가 동양화 정서와 잘 맞는다.

2. **모바일에서 잘 읽힌다**
   수묵담채는 색 수가 적고 명암 대비가 커서 작은 화면에서도 형태가 또렷하다.
   여백이 많아 터치 버튼과 텍스트를 얹을 공간이 자연스럽게 생긴다.

3. **제작비가 적게 든다**
   전투를 토큰으로 표현하면 캐릭터 애니메이션(걷기·공격 프레임)이 필요 없다.
   인물 1명에 초상 1장이면 되고, 연출은 트윈(이동·흔들림)과 파티클(먹 번짐)로 처리한다.
   1인 개발이나 소규모 외주 일정에 맞는다.

4. **여러 플랫폼에 그대로 쓴다**
   정적인 2D 일러스트는 해상도만 넉넉히 만들면 휴대폰부터 4K TV까지 같은 에셋을 쓸 수 있다.
   현재 렌더러(GL Compatibility)로 충분해서 웹과 저사양 모바일에서도 가볍다.

5. **눈에 띈다**
   무협 모바일 게임은 대부분 애니풍 셀 일러스트나 3D다. 수묵 전략 게임은 상대적으로 드물어
   스토어 썸네일에서 구별된다.

## 3. 비교한 대안

| 방향 | 장점 | 단점 | 판단 |
|---|---|---|---|
| **수묵담채 + 토큰 (제안)** | 기획 일치, 모바일 가독성, 저비용, 차별성 | 화풍 일관성 유지가 어렵다 (스타일 가이드 필수) | 추천 |
| 픽셀 아트 | 제작 도구·인력이 많고 저렴, 애니메이션 쉬움 | 산수화 기획과 어긋남, 인디 전략 게임에서 흔함, 고해상도 화면에서 작게 보임 | 차선 |
| 애니풍 셀 일러스트 | 무협 게임 이용자에게 익숙함, 캐릭터 매력 강조 | 인물마다 비용이 큼, 경쟁작과 겹침 | 비추천 |
| 3D / 2.5D | 연출 폭이 넓음 | 범위·비용 초과, 저사양 모바일·웹 부담 | 제외 |

## 4. 스타일 가이드 초안

### 4.1 색

| 용도 | 색 | 메모 |
|---|---|---|
| 바탕 (화선지) | `#EFE6D2` | 낮 테마 기본 바탕 |
| 먹 | `#1E1E1E` | 본문, 선 |
| 담묵 | `#7A746A` | 보조 텍스트, 비활성 |
| 주홍 (낙관) | `#B23A2B` | 강조, 적, 경고 |
| 청록 | `#2F6B5E` | 아군, 정파, 확인 |
| 금 (소량) | `#C9A54B` | 등급·희귀도 표시에만 |

- **낮/밤 두 테마**: 화선지 바탕의 낮 테마를 기본으로 하고, 지금 쓰는 어두운 남색 + 금색 UI는
  "먹 바탕 밤 테마"로 다듬어 옵션으로 남긴다.
- 정보는 색만으로 구분하지 않는다. 아군·적 표시는 색과 테두리 모양(원·팔각)을 함께 쓴다 (색각 이상 대응).

### 4.2 글꼴

- 제목: 붓글씨체 (예: 나눔손글씨 붓 계열, SIL OFL)
- 본문: Noto Sans KR 또는 Noto Serif KR (SIL OFL)
- 웹 빌드 용량을 위해 사용 글자만 담는 서브셋 폰트를 만든다.

### 4.3 해상도와 규격

| 에셋 | 제작 크기 | 비고 |
|---|---|---|
| 화면 배경 | 2560×1440 | 기준 해상도 1280×720의 2배 |
| 인물 초상 | 512×640 | 토큰은 같은 그림에서 원형으로 잘라 씀 |
| 전투 토큰 | 128×128 | 상태(기절 등)는 토큰 위 아이콘으로 표시 |
| 지형 타일 | 96×96 | 격자 48px의 2배 |
| UI 아이콘 | 64×64 단색 | 벡터(SVG) 원본 유지 |

- 화면 비율: 휴대폰의 19.5:9부터 태블릿의 4:3까지 대응해야 한다.
  `stretch/aspect`를 `expand`로 두고, 배경은 좌우로 넉넉히 그려 넓은 화면에서 잘리지 않게 한다.

## 5. 제작 순서

1. **스타일 견본 (1~2주)**: 배경 1장, 초상 2장(청운검선·남궁휘), 지형 타일 1세트, UI 버튼·패널 키트
2. **실기 확인**: 견본을 넣은 빌드를 실제 휴대폰과 PC에서 확인한다. 가독성과 터치 크기를 점검한다
3. **확정**: 스타일 가이드를 이 문서에 확정본으로 반영한다
4. **양산**: 배경 6장, 초상(NPC 전원 + 시작 역할 3종 + 제자 공용), 타일셋, 이펙트, 아이콘
5. **연결**: NPC JSON의 `portrait`, 세력 JSON의 `emblem`, 전투 렌더링을 `TileMapLayer`와 `Sprite2D`로 교체

## 6. 조달 시 주의점

- **외주**: 스타일 견본을 먼저 의뢰해 화풍을 고정한 뒤 양산을 맡긴다. 저작권 양도와 2차 사용 범위를 계약서에 명시한다.
- **생성 도구**: 쓰는 경우에는 스타일 참조를 고정하고 사람이 손으로 정리한다. 스토어별 AI 생성물 고지 정책(Steam 등)을 확인하고, 학습 데이터 라이선스가 명확한 도구를 고른다.
- **무료 에셋**: 수묵 스타일은 무료 에셋이 적다. UI 질감이나 붓 브러시 정도만 활용하고, 라이선스(상업 이용, 표기 의무)를 기록해 둔다.

## 7. 사운드 방향 (참고)

화풍과 맞춰 국악·중국 전통악기(가야금, 고쟁, 대금, 퉁소)와 북 중심의 타악으로 간다.
경영 화면은 잔잔한 독주, 전투는 타악 위주로 편성한다.
효과음은 붓 소리, 종이 넘김, 검 부딪힘, 도장 찍는 소리처럼 화풍에 맞는 질감으로 맞춘다.
