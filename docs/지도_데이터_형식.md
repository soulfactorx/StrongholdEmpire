# 강호 지도 데이터 형식

강호 지도는 `data/map/regions.json` 한 파일이다. 읽기·검증은 `scripts/Systems/world_map.gd`(`WorldMap`)가 맡는다.
판마다 바뀌는 지역 주인과 본거지는 `GameManager.map_state`(`{owners: {지역: 세력 id}, homes: {세력 id: 지역}}`)에 담겨 저장된다.

```json
{
  "size": [900, 700],
  "spare_homes": ["xian", "kaifeng"],
  "regions": [
    {
      "id": "qingyun", "name": "청운산", "pos": [530, 420], "home": "qingyun",
      "gold": 10, "food": 8, "defense": 60,
      "description": "구름이 감도는 검산. 청운검파의 산문이 있다.",
      "neighbors": ["luoyang", "kaifeng", "hefei", "wudang", "wuchang"]
    }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `size` | 지도 좌표의 크기 [가로, 세로]. 화면에 맞춰 늘이고 줄인다 |
| `spare_homes` | 지도에 본거지가 없는 세력(시나리오 전용 세력 등)이 받을 빈 땅 순서 |
| `id`, `name` | 지역 id와 이름 (지도 버튼에 보인다. 3글자 안쪽 권장) |
| `pos` | 지도 좌표 [x, y] |
| `home` | 이 땅을 본거지로 쓰는 세력 id. 그 세력이 판에 나오면 처음부터 그 세력 땅이고, 아니면 주인 없는 땅 |
| `gold`, `food` | 본거지가 아닌 주인에게 계절마다 주는 금화·식량 |
| `defense` | 주둔 병력. 평정(플레이어)·확장(세력 AI)하려면 전력이 이 값 이상이어야 하고, 평정 금화는 60 + 주둔 병력 / 2 |
| `neighbors` | 맞닿은 지역 id. 양쪽 지역에 모두 적어야 한다(검증) |
| `background` | (선택) 이 지역에 있을 때 경영 화면 배경 그림 (`assets/art/` 기준 경로). 없으면 `bg/regions/<id>.jpg`, 그것도 없으면 `bg/hub.jpg`. 지역 배경은 `tools/art/generate_region_bg.py`로 만든다 |

규칙
- 본거지는 빼앗기지 않는다. 남의 본거지를 꺾으려면 문파전으로 굴복시킨다.
- 땅을 얻으면 제자 정원 +3, 잃으면 −3 (`GameBalance.REGION_MAX_DISCIPLES`).
- 문주만 땅을 넓힌다. 맞닿은 빈 땅은 [평정](계절에 한 번), 남의 땅은 [공략](문파전에서 이기면 차지).
  문파전에서 이기면 공략으로 고른 땅을, 없으면 맞닿은 상대 땅 하나를 차지한다.
- 침공을 막지 못하거나 산문을 내주면, 침략 세력과 맞닿은 우리 땅부터 하나를 잃는다.
- 세력 AI는 전략에 따라 빈 땅을 차지하고(확장), 세력 전쟁에서 이기면 맞닿은 땅을 빼앗는다.
- 기연·엔딩 조건 `regions_owned`(op, value)로 우리 문파의 땅 수를 본다.
- 플레이어는 늘 한 지역에 있다(`GameManager.player_region`). 문파 일을 하는 역할은 본거지에, 무소속은 처음에 낙양(`GameBalance.START_REGION`)에 있다.
  낭인·의뢰인·간자·자객은 지도에서 지역을 골라 옮긴다 (계절에 한 번, 여비 한 걸음에 금화 5).
  남의 땅에 있으면 의뢰 보상이 크고 위험하며, 그 땅 주인 세력의 신용이 오른다.
