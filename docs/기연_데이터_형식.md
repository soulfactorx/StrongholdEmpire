# 기연 데이터 형식

기연은 `data/events/` 폴더의 JSON 파일 하나당 하나씩 정의합니다.
게임을 시작할 때 모두 불러오며, 형식이 잘못된 파일은 경고를 남기고 건너뜁니다.
해석기는 `scripts/Systems/event_manager.gd`에 있습니다.

## 예시

```json
{
  "id": "night_bandits",
  "title": "야습 도적",
  "description": "문파 외곽에서 도적 무리가 습격해옵니다!",
  "can_repeat": false,
  "conditions": [
    { "type": "season", "in": ["가을"] }
  ],
  "choices": [
    {
      "label": "맞서 싸운다",
      "message": "도적 무리를 막아서기 위해 검을 뽑습니다!",
      "effects": [ { "type": "combat", "combat": "night_bandits" } ]
    },
    {
      "label": "은밀히 피한다",
      "message": "은밀히 피해 신법 +1.",
      "effects": [ { "type": "character", "field": "agility", "add": 1 } ]
    }
  ]
}
```

## 최상위 필드

| 필드 | 설명 |
|---|---|
| `id` | 고유 id. 파일끼리 겹치면 나중 파일은 무시됩니다. |
| `title`, `description` | 팝업에 표시되는 제목과 본문 (`\n`으로 줄바꿈) |
| `can_repeat` | `false`면 한 번 발생한 뒤 다시 나오지 않습니다. |
| `conditions` | 모두 만족해야 발생합니다. 빈 배열이면 항상 후보가 됩니다. |
| `choices` | 선택지 목록. 개수 제한은 없습니다. |

## 조건

| type | 필드 | 의미 |
|---|---|---|
| `character` | `field`, `op`, `value` | 캐릭터 능력치 비교. `martial_arts_count`는 습득 무공 수 |
| `sect` | `field`, `op`, `value` | 문파 자원·시설 비교 |
| `bond` | `target`, `op`, `value` | 관계 유대 수치 비교 (`npc_master`, `npc_rival`) |
| `role` | `in` | 현재 역할이 목록에 있음 (`LEADER`, `MANAGER`, `YOUNG_DISCIPLE`, `WANDERER`, `SPY`, `ASSASSIN`, `MERCENARY`) |
| `season` | `in` | 현재 계절이 목록에 있음 (`봄`, `여름`, `가을`, `겨울`) |
| `flag` | `flag`, `value` | 스토리 플래그 값이 같음 (없는 플래그는 `false`) |

- `op`: `>=`, `<=`, `>`, `<`, `==`, `!=`
- 캐릭터 필드: `strength`, `agility`, `wisdom`, `charisma`, `morality`, `internal_energy_current`, `internal_energy_max`, `level`, `age`
- 문파 필드: `gold`, `food`, `reputation`, `research_points`, `disciple_count`, `max_disciples`, `library_level`, `training_ground_level`, `treasury_level`

## 선택지

| 필드 | 설명 |
|---|---|
| `label` | 버튼 문구 |
| `message` | 선택 후 로그에 표시할 결과 문구 |
| `effects` | 적용할 효과 목록 |
| `branches` | (선택) `chance`(1~100), `message`, `effects`를 가진 확률 분기 목록. 위에서부터 굴려 처음 걸린 분기가 기본 `message`/`effects`를 대신합니다. |
| `success` | (선택) `false`면 실패 효과음. 기본값 `true` |

## 효과

| type | 필드 | 의미 |
|---|---|---|
| `character` | `field`, `add` | 능력치 증감. 내공은 0~최대치로 제한 |
| `sect` | `field`, `add` | 문파 자원 증감. 0 미만으로 내려가지 않음 |
| `experience` | `amount` | 경험치 획득 (레벨업 포함) |
| `bond` | `target`, `add` | 유대 증감 |
| `flag` | `flag`, `value` | 스토리 플래그 설정 (`value` 생략 시 `true`) |
| `combat` | `combat` | 전투 시작: `sparring`, `rival_duel`, `night_bandits` |
