# 기연 데이터 형식

기연은 `data/events/` 폴더의 JSON 파일 하나당 하나씩 정의합니다. 하위 폴더도 읽으므로
스토리 아크는 `data/events/arcs/<아크 이름>/`처럼 묶어 둡니다.
시나리오 전용 기연은 `data/scenarios/<id>/events/`에 둡니다 (`docs/시나리오_데이터_형식.md`).
게임을 시작할 때 모두 불러오며, 형식이 잘못된 파일은 경고를 남기고 건너뜁니다.
해석기는 `scripts/Systems/event_manager.gd`에 있습니다.

## 예시

```json
{
  "id": "night_bandits",
  "title": "야습 도적",
  "description": "문파 외곽에서 도적 무리가 습격해옵니다!",
  "can_repeat": false,
  "conditions": [
    { "type": "season", "in": ["가을"] }
  ],
  "choices": [
    {
      "label": "맞서 싸운다",
      "message": "도적 무리를 막아서기 위해 검을 뽑습니다!",
      "effects": [ { "type": "combat", "combat": "night_bandits" } ]
    },
    {
      "label": "은밀히 피한다",
      "message": "은밀히 피해 신법 +1.",
      "effects": [ { "type": "character", "field": "agility", "add": 1 } ]
    }
  ]
}
```

## 최상위 필드

| 필드 | 설명 |
|---|---|
| `id` | 고유 id. 파일끼리 겹치면 나중 파일은 무시됩니다. |
| `title`, `description` | 팝업에 표시되는 제목과 본문 (`\n`으로 줄바꿈) |
| `can_repeat` | `false`면 한 번 발생한 뒤 다시 나오지 않습니다. |
| `weight` | (선택) 발생 후보 중 뽑힐 상대적 확률. 기본 1. 스토리 핵심 기연은 2~5로 높입니다. |
| `conditions` | 모두 만족해야 발생합니다. 빈 배열이면 항상 후보가 됩니다. |
| `choices` | 선택지 목록. 개수 제한은 없습니다. |

## 조건

| type | 필드 | 의미 |
|---|---|---|
| `character` | `field`, `op`, `value` | 캐릭터 능력치 비교. `martial_arts_count`는 습득 무공 수 |
| `sect` | `field`, `op`, `value` | 문파 자원·시설 비교 |
| `bond` | `target`, `op`, `value` | 관계 유대 수치 비교 (`npc_master`, `npc_rival`) |
| `role` | `in` | 현재 역할이 목록에 있음 (`LEADER`, `MANAGER`, `YOUNG_DISCIPLE`, `WANDERER`, `SPY`, `ASSASSIN`, `MERCENARY`) |
| `season` | `in` | 현재 계절이 목록에 있음 (`봄`, `여름`, `가을`, `겨울`) |
| `flag` | `flag`, `value` | 스토리 플래그 값이 같음 (없는 플래그는 `false`) |
| `world_sect` | `sect`, `field`, `op`, `value` | 강호 세력 수치 비교. `field`는 `attitude`, `reputation`, `disciple_count`, `subjugated`(0/1) |
| `year` | `op`, `value` | 현재 연차 비교 (1년차부터) |
| `turns_since_flag` | `flag`, `op`, `value` | 플래그가 켜진 뒤 지난 계절 수 비교. 켜진 적 없거나 꺼져 있으면 거짓 |
| `relationship_type` | `target`, `bond_type` | 그 인물과의 관계 유형이 일치. 관계가 없으면 거짓 |
| `role_history` | `role`, `value` | 이번 인물이 그 역할을 거쳐 왔는지. `value: false`면 "거친 적 없음" |
| `scenario` | `in` | 현재 시나리오 id가 목록에 있음 |
| `years_left` | `op`, `value` | 시나리오 제한까지 남은 연수 (제한이 없으면 9999) |
| `subjugated_count` | `op`, `value` | 굴복시킨 강호 세력 수 |
| `generation` | `op`, `value` | 현재 세대 (1세대부터) |
| `role_state` | `field`, `op`, `value` | 역할 자원 비교. `field`: `discontent`(문주 불만도), `trust`(중간관리자 신임도), `exposure`(스파이 노출도), `bounty`(암살자 현상금), `failures`(실책), `intel_count`(정보 수집 횟수) |

- `op`: `>=`, `<=`, `>`, `<`, `==`, `!=`
- 캐릭터 필드: `strength`, `agility`, `wisdom`, `charisma`, `morality`, `internal_energy_current`, `internal_energy_max`, `level`, `age`
- 문파 필드: `gold`, `food`, `reputation`, `research_points`, `disciple_count`, `max_disciples`, `library_level`, `training_ground_level`, `treasury_level`, `apothecary_level`, `meditation_hall_level`

## 선택지

| 필드 | 설명 |
|---|---|
| `label` | 버튼 문구 |
| `message` | 선택 후 로그에 표시할 결과 문구 |
| `effects` | 적용할 효과 목록 |
| `branches` | (선택) `chance`(1~100), `message`, `effects`를 가진 확률 분기 목록. 위에서부터 굴려 처음 걸린 분기가 기본 `message`/`effects`를 대신합니다. |
| `success` | (선택) `false`면 실패 효과음. 기본값 `true` |

## 효과

| type | 필드 | 의미 |
|---|---|---|
| `character` | `field`, `add` | 능력치 증감. 내공은 0~최대치로 제한 |
| `sect` | `field`, `add` | 문파 자원 증감. 0 미만으로 내려가지 않음 |
| `experience` | `amount` | 경험치 획득 (레벨업 포함) |
| `bond` | `target`, `add` | 유대 증감 |
| `flag` | `flag`, `value` | 스토리 플래그 설정 (`value` 생략 시 `true`) |
| `combat` | `combat` | 전투 시작. 코드 전투(`sparring`, `rival_duel`, `night_bandits`, `bandit_hunt`, `assassination`, `bounty_hunters`) 또는 `data/combats/`의 데이터 전투 id (`docs/전투_데이터_형식.md`) |
| `world_sect` | `sect`, `field`, `add` | 강호 세력 수치 증감. 태도는 -100~100, 나머지는 0 미만으로 내려가지 않음 |
| `set_bond_type` | `target`, `bond_type` | 기존 관계의 유형을 바꿈 (관계가 없으면 무시) |
| `add_relationship` | `target`, `bond_type`, `strength` | 명부 인물과 새 관계를 맺음. 이미 관계가 있으면 무시. `strength` 기본 10 |
| `learn_art` | `art` | 무공 습득. `resources/MartialArts/`의 프리셋 id 또는 모드 무공 id |
| `end_game` | `ending` | 지정한 엔딩(`docs/엔딩_데이터_형식.md`)에 도달하거나 게임오버(`GAME_OVERS`)로 끝냄 |
| `role_state` | `field`, `add` | 역할 자원 증감 (0~100으로 제한). 필드는 조건과 같음 |

- `bond_type`: `MASTER_DISCIPLE`(사제), `ROMANCE`(연애), `BLOOD_OATH`(혈맹), `RIVALRY`(라이벌), `HATRED`(원한)

`world_sect`의 `sect`는 `data/sects/`의 문파 id 중 플레이어 문파가 아닌 것이어야 합니다.
굴복 여부는 `flag` 조건으로 `subjugated_<문파 id>`를 확인합니다.

## 연쇄 기연(스토리 아크) 작성법

여러 기연을 이어 하나의 이야기로 만들 때는 플래그로 단계를 잇습니다.

1. 첫 기연의 선택지에서 `flag` 효과로 단계 플래그를 켭니다. (예: `arc_revenge_start`)
2. 다음 기연은 `turns_since_flag`로 "앞 단계 뒤 N계절이 지나면" 발생하게 합니다.
   `turns_since_flag`는 플래그가 켜져 있을 때만 참이므로 플래그 조건을 따로 걸 필요가 없습니다.
3. 핵심 단계는 `weight`를 높여(4~5) 무작위 기연에 묻히지 않게 합니다.
4. 전투로 갈리는 단계는 데이터 전투의 `victory_flag`·`defeat_flag`로 다음 기연을 나눕니다.
   진 뒤 다시 도전하는 기연은 `can_repeat: true`에 "아직 이기지 않았음" 조건(`flag ... false`)을 겁니다.
5. 마지막 단계에서 `end_game`으로 아크 엔딩(`auto: false`)에 이르는 선택지와,
   엔딩 없이 이야기를 이어 가는 선택지를 함께 둡니다. 엔딩은 세대마다 하나뿐이기 때문입니다.
6. 스모크 테스트의 `_test_story_arcs`에 선택지를 고정한 진행 경로를 추가합니다.

### 현재 스토리 아크 (`data/events/arcs/`)

| 폴더 | 아크 | 시작 조건 | 갈림길과 엔딩 |
|---|---|---|---|
| `revenge` | 복수와 용서 | 막내 제자·중간관리자, 2년 이후, 스승 유대 30 | 귀영 결투(패배 시 재도전) → 처단 / 용서(`mercy_blade`) / 배후 마진 토벌 |
| `succession` | 승계와 배신 | 막내 제자·중간관리자, 3년 이후 | 반란 진압 → 후계 지명(승진 조건 완화) / 가담 → 스승 습격 → 찬탈자(`usurper`) 또는 파문 |
| `love` | 금단의 사랑 | 2년 이후 봄, 40세 이하 | 청혼 → 가주의 시험 → 혼례(`marriage_alliance`) / 도주 → 추격전 → 은거(`hidden_valley`, 생을 마침) 또는 비극(`fallen_blossom`) |
| `spy` | 스파이 이중생활 | 스파이, 정보 수집 1회 이상 | 노출 위기 3회(구출 전투·집법당주 결판, 지면 처형) → 충성 / 전향 / 이중첩자(`web_of_shadows`) |
| `cheonma` | 마교 대침공 | 천하대란 시나리오, 5년 이후, 혈영의 밀서를 거절 | 연합 회의 → 혈영 습격 → 산문 방어전(연합군·단독) → 천마 결전(`demon_slayer`) / 함락(`fallen_sect`) |

예시: 「남궁휘와의 결의」는 라이벌 결투 승리(`won_rival_duel`) 4계절 뒤,
관계가 아직 라이벌(`relationship_type`)이고 유대가 40 이상일 때 발생하며,
선택에 따라 관계를 혈맹으로 바꿉니다(`set_bond_type`).

플래그는 기연뿐 아니라 게임에서도 켜집니다:
`won_rival_duel`(라이벌 결투 승리), 데이터 전투의 `victory_flag`·`defeat_flag`, `won_sect_war`, `defeated_<문파 id>`, `subjugated_<문파 id>`, `ending_reached`
